## Control flow

### Conditional

<Tabs groupId="go-conditional">
<TabItem value="if" label="if" default>

```go
if age > 18 {
    fmt.Println("Adult")
} else if (age > 14) {
    fmt.Println("Minor")
} else {
    fmt.Println("Child")
}
```

</TabItem>
<TabItem value="switch" label="switch">

```go
switch day {
case "Monday":
    fmt.Println("Start of the week")
case "Tuesday", "Wednesday", "Thursday", "Friday", "Saturday":
    fmt.Println("Midweek")
case "Sunday":
    fmt.Println("End of the week")
default:
    fmt.Println("Not the day")
}
```

```go
// Switch with conditions - no need for break
switch {
case score >= 90:
    fmt.Println("A")
case score >= 80:
    fmt.Println("B")
default:
    fmt.Println("C or below")
}
```

```go
// fallthrough - continue to next case
// The fallthrough must be the last statement in the case block
switch {
case score >= 90:
    fmt.Println("A")
    fallthrough
case score >= 80:
    fmt.Println("B")
    fallthrough
default:
    fmt.Println("C or below")
}
// If score is 95, output will be:
// A
// B
// C or below
```

</TabItem>
</Tabs>

### Loops

<Tabs groupId="go-loops">
<TabItem value="for" label="for (classic)" default>

```go
// declare; condition; update
for i := 0; i < 5; i++ {
    fmt.Println(i)
}
```

</TabItem>
<TabItem value="while" label="for (condition / infinite)">

```go
// Infinity -> for condition {}
for {
    // do something and break or return
}
```

</TabItem>
<TabItem value="range" label="for range">

```go
// Iterate over collection
for index, value := range collection {
    fmt.Println(index, value)
}
// If index is not needed
for _, value := range collection {
    fmt.Println(value)
}
```

</TabItem>
<TabItem value="label" label="labels">

```go
// Nested loops with label, this can be used with break and continue
outer:
    for userInput != 0 {
        switch userInput {
        case 1:
            // something
        // ...
        default:
            break outer // exit loop
        }
    }
```

</TabItem>
</Tabs>
