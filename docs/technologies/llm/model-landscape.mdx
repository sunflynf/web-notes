# Model Landscape

## Anthropic Claude (verified)

| Model | API ID | Positioning (from Anthropic docs) |
|---|---|---|
| Claude Fable 5.1 | `claude-fable-5-1` | Demanding reasoning and long-horizon agentic work |
| Claude Opus 5.5 | `claude-opus-5-5` | Long-running agentic coding and knowledge work; recommended default |
| Claude Sonnet 5.5 | `claude-sonnet-5-5` | Best combination of speed and intelligence |
| Claude Haiku 5.5 | `claude-haiku-5-5` | Fastest; high-volume classification, extraction, routing |

- All four list a 1M-token context window, text + image input, tool use and adaptive thinking.
- Dateless IDs (from the 4.6 generation on) are pinned snapshots, not moving aliases.
- Older models (Claude 5, 4.x) remain available as legacy; see the deprecations page for retirement dates.

## How to choose

1. Start with a strong general model to see if the task is feasible.
2. Build an eval set ([Evals](./evals.mdx)).
3. Try cheaper/faster models against it; keep the cheapest one that passes.
4. Need privacy/offline/self-hosting → open weights ([Local Models](./local-models.mdx)).
5. Re-run evals when vendors ship new versions.
