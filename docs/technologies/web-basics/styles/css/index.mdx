# CSS3

> **Quick reference:** [CSS Cheatsheet](./cheatsheet.mdx)

- Describes how HTML elements are to be displayed on screen, paper, or in other media
- Control the layout of multiple web pages all at once
- External stylesheets are stored in CSS files ➡️ CSS removed the style formatting from the HTML page!
- There is no "CSS4": since CSS3 the language is split into modules with their own levels; the W3C publishes a yearly [CSS Snapshot](https://www.w3.org/TR/css-2026/) of what is stable
