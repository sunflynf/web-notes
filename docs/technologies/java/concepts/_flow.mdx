### Switch - case - default

<Tabs groupId="java-switch">
<TabItem value="statement" label="switch statement" default>

```java
enum Day { MON, TUE, WED, THUR, FRI, SAT, SUN }

public static Boolean isWeekDay(Day day) {
    boolean result = false;
    switch(day) {
        case MON, TUE, WED, THUR, FRI:
            result = true;
            break;
        case SAT, SUN:
            result = false;
            break;
        default:
            throw new IllegalArgumentException("Invalid day: " + day.name())
    }
    return result;
}
```

</TabItem>
<TabItem value="expression" label="switch expression">

```java
// switch + arrow break (JDK 13+)
int day = 3;
String dayType = switch (day) {
    case 1, 2, 3, 4, 5 -> "Weekday";
    case 6, 7 -> "Weekend";
    default -> "Invalid day";
};
```

</TabItem>
<TabItem value="pattern" label="pattern matching">

```java
// instanceof parsing (JDK 17+)
Object o;
switch (o)
{
    case Integer i -> String.format("int %d", i);
    case Double d  -> String.format("double %f", d);
    case String s  -> String.format("String %s", s);
    default        -> o.toString();
}
```

**While, Do - while Loop**

```java

    sum += i;
    i++;
}

    i++;
} while(i <= 5)
```

#### Try-with-resources

```java
try (BufferedReader br = new BufferedReader(new FileReader("C:/temp/test.txt"))) {
    String sCurrentLine;
    while ((sCurrentLine = br.readLine()) != null) {
        System.out.println(sCurrentLine);
    }
}
catch (IOException e) {
    // handle exception
}
```
