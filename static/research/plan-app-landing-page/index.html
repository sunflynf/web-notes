Lộ trình Phát triển theo Tuần

Mục tiêu:

  • Khởi tạo dự án Next.js & cài đặt Tailwind CSS.
  • Xây dựng layout chính: Header, Sidebar, Canvas.
  • Tạo các UI components tĩnh (TextBlock, ImageBlock, etc.).
  • Hiểu rõ cấu trúc thư mục của dự án.

Mục tiêu:

  • Triển khai State Management với React Context.
  • Tích hợp chức năng kéo-thả từ sidebar vào canvas.
  • Xây dựng panel thuộc tính để chỉnh sửa các block.
  • Đảm bảo Live Preview cập nhật theo thời gian thực.

Mục tiêu:

  • Thiết kế Schema và kết nối MongoDB.
  • Xây dựng các API Routes cho CRUD Landing Pages.
  • Triển khai chức năng Lưu/Tải trang từ database.
  • Tạo API để thu thập dữ liệu từ Form.

Mục tiêu:

  • Triển khai chức năng xuất file HTML/CSS.
  • Đảm bảo tool và trang được tạo responsive.
  • Hoàn thiện UI/UX, thêm thông báo, viết README.
  • Sẵn sàng để deploy lên Vercel.

Luận giải về Kiến trúc

/components

Chia nhỏ các thành phần giao diện. `blocks` là các khối xây dựng trang, `layout` là cấu trúc chính, và `ui` là các thành phần nhỏ tái sử dụng.

/contexts

Nơi quản lý state toàn cục. `PageContext` sẽ là "nguồn chân lý" cho cấu trúc landing page đang được chỉnh sửa.

/lib & /models

Tách biệt logic nghiệp vụ. `lib` chứa các hàm tiện ích và kết nối DB, `models` định nghĩa schema cho cơ sở dữ liệu.

/pages

Cấu trúc routing của Next.js. `pages/api` chứa toàn bộ backend, giúp dự án trở thành một full-stack monolith, dễ quản lý cho junior.
